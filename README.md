🐍 Functional Treat
> **Data Analyzer and Transformer in Python**
Functional Treat is a menu-driven Python project that demonstrates
different function-based concepts while working with 1D and 2D
lists.
---
✨ Project Overview
The project allows the user to enter or use sample data and perform
different analysis and transformation operations.
🎯 Concepts Demonstrated
🔹 Built-in functions such as `len()`, `sum()`, `min()`, and `max()`
🔹 User-defined functions (UDFs)
🔹 `*args`
🔹 `**kwargs`
🔹 Function documentation using `__doc__`
🔹 Recursion using factorial
🔹 Lambda functions
🔹 `map()` and `filter()`
🔹 `global` keyword
🔹 Returning multiple values
🔹 1D and 2D lists
🔹 Sorting with `sort()` and `sorted()`
🔹 Menu-driven interface
---
🧩 Main Features
📊 Basic Statistics
The program displays: - Number of values - Sum - Minimum value - Maximum
value - Average
🔧 User-Defined Functions
Separate functions are used for: - Calculating average - Finding
duplicate values - Displaying unique values
📦 `*args` and `**kwargs`
`*args` is used to accept and display multiple values.
`**kwargs` is used to display dataset characteristics as key-value
pairs.
📚 `__doc__`
Each function contains a documentation string describing its purpose.
The program also includes an option to display the function
documentation.
🔁 Recursion
A recursive `factorial()` function demonstrates recursion.
⚡ Lambda, Map & Filter
The project uses lambda functions with: - `filter()` to find values
above or below a user-defined threshold - `map()` to transform values by
multiplying them by 2
🌐 Global Variable
A global `dataset_summary` stores: - Total number of values - Overall
mean
↩️ Multiple Return Values
The `multiple_statistics()` function returns: - Minimum - Maximum -
Average
🧮 1D & 2D Lists
The program supports both 1D and 2D list data.
The 2D list is displayed in a simple grid format.
🔃 Sorting
For 1D data, the project demonstrates `sort()` for ascending and
descending order.
For 2D data, `sorted()` is used to create a sorted version while
displaying the original data as well.
